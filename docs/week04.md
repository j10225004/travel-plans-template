# 第4週: ページを増やす

## 今週のゴール

大きめの機能（新しいページ・絞り込み）を、**小さく分けて**頼み、1つずつ確かめながら作れる。

## 1. 大きな頼みごとは分ける

「詳細ページと検索を作って」と一度に頼むと、何ができたのか確かめにくくなります。
先に Claude と一緒に「作る順番」を決めましょう。

```
プランの詳細ページと、地域で絞り込む機能を作りたい。
いきなり作らずに、確認しながら進められるように3〜4つの手順に分けて提案して。
```

提案された手順を読み、順番や中身に納得できたら、1つ目だけを頼みます。

## 2. 課題A: プランの詳細ページ

一覧のカードを押すと、そのプランの詳しいページが開くようにします。
詳細ページに何を載せるかは、自分で決めてください。`data/plans.json` には、見どころ（highlights）など一覧に出ていない情報も入っています。

頼み方の例（このまま使わず、自分の言葉にしてください）:

```
プラン一覧のカードを押したら、そのプランの詳細ページが開くようにしたい。
詳細ページには、タイトル・日数・価格・紹介文・見どころの一覧を載せて。
一覧に戻るリンクも付けて。
```

確かめること:

- どのカードを押しても、正しいプランが表示されるか
- 戻るリンクで一覧に戻れるか
- スマホの幅でも崩れないか（Claude に「スマホの幅で確認する方法を教えて」と聞けます）

## 3. 課題B: 地域で絞り込む

プラン一覧で、地域（関西・沖縄 など）を選ぶと、その地域のプランだけが表示されるようにします。
見せ方（ボタンを並べる・選択リストにする など）は自分で決めてください。迷ったら Claude に「見せ方の案を3つ出して」と頼みましょう。

## 4. 余裕があれば

- 価格の安い順・日数の短い順に並べ替える
- 「該当するプランがありません」の表示を作る

## 5. 提出

課題A・B は、それぞれ別の PR にしても、1つの PR にまとめてもかまいません。
「うまくいかなかったこと と 言い直した指示」の欄に、**手順を分けたことで何が楽になったか（または困ったか）** も書いてください。

## 今週わかったこと

- 大きな機能は、先に手順を分けてもらってから1つずつ頼む
- 「何を載せるか」「どう見せるか」は自分が決める。迷ったら案を出してもらって選ぶ
