# 第7週: ログインと管理画面

## 今週のゴール

管理者だけがログインして、プランの追加・削除と、問い合わせの確認ができる「管理画面」を作る。
「画面を隠す」ことと「データを守る」ことの違いを知る。

## 1. 管理者のユーザーを作る（5分）

1. Supabase の左のメニューから **Authentication** →「Users」
2. 「Add user」→「Create new user」
3. メールアドレスとパスワードを入れる（練習用のものでかまいません）。「Auto Confirm User」にチェック
4. 「Create user」

続けて、知らない人が勝手にユーザー登録できないようにします。

5. Authentication の「Sign In / Providers」（または「Settings」）で、**Allow new users to sign up** をオフにして保存

## 2. 管理者の権限を作る（5分）

1. Codespaces で `supabase/03_admin.sql` を開き、中身を全部コピーする
2. Supabase の SQL Editor に貼り付ける
3. 一番下の `'admin@example.com'` を、さっき作ったユーザーのメールアドレスに書き換える
4. Run を押す

これで RLS に次の決まりが加わります。

| 表 | 管理者ができること（追加分） |
| --- | --- |
| plans | 追加・変更・削除 |
| inquiries | 見る |

## 3. 画面を隠すだけでは守れない

管理画面のリンクをどこにも置かなくても、URL を知っている人は開けます。ボタンを隠しても、仕組みを知っている人は直接データベースに命令を送れます。
**データを守っているのは、画面ではなく RLS です。** 画面はあくまで「管理者が使いやすくするためのもの」と考えます。

## 4. Claude に管理画面を作ってもらう（50分）

一度に頼まず、手順を分けてもらいましょう（第4週の復習です）。

```
管理画面を作りたい。管理者が Supabase のメールアドレスとパスワードでログインして、
プランの追加・削除と、問い合わせの一覧を見られるようにしたい。
データの守りは Supabase の RLS で設定済み。
いきなり作らずに、確認しながら進められる手順に分けて提案して。
```

決めておくとよいこと:

- 管理画面の URL（例: `/admin`）
- ログインしていないとき・管理者でない人がログインしたときに何を表示するか
- プランを追加するときの入力項目（緯度・経度は第8週の天気で使います。地図アプリで行き先を右クリックすると調べられます）
- 削除のときに確認を出すか

## 5. 確かめる

| 試すこと | 期待する結果 |
| --- | --- |
| 正しいメールアドレスとパスワードでログイン | 管理画面が開く |
| 間違ったパスワードでログイン | わかりやすいメッセージが出る |
| プランを1つ追加して、トップや一覧を開く | 追加したプランが表示される |
| 追加したプランを削除する | 一覧から消える |
| 第6週で送った問い合わせ | 管理画面に表示される |
| ログアウトしてから管理画面を開く | プランの追加や問い合わせが見えない |

## 6. 提出

PR を作って提出します。「結果」欄には上の表のうち確かめた項目を書いてください。
プレビュー URL を提出するときは、管理者のパスワードを PR に書かないでください。

## つまずいたら

| 症状 | 対処 |
| --- | --- |
| ログインできない | Users にユーザーがいるか、「Auto Confirm User」にチェックしたかを確認します |
| ログインできるが「権限がない」と出る | `03_admin.sql` のメールアドレスを書き換えて実行したか確認します。Table Editor の「admins」に1行入っていれば正しく登録されています |
| 追加したプランが本番に出ない | Claude に「Supabase から読むページは毎回最新を表示する設定にして」と頼みます |
