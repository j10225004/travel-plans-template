# たびプラン — Claude Code 演習テンプレート

プログラミング未経験の人が、AI（Claude Code）に指示を出して Web サイトを作り、公開し、直していく16週間の自習教材です。

- 題材: 旅行プラン紹介サイト（Next.js、Supabase、Vercel）
- 進め方: [docs/README.md](docs/README.md) を読んでください

## はじめかた（受講者向け）

1. この画面の右上にある緑色の **Use this template** →「Create a new repository」を押す
2. Repository name に `travel-plans` と入れ、**Private** を選んで「Create repository」
3. できた自分のリポジトリで **Code** →「Codespaces」タブ →「Create codespace on main」
4. あとは [docs/week01.md](docs/week01.md) の手順に沿って進めます

## 注意

- これは個人の学習用の教材です。会社の情報・顧客情報・個人情報は入れないでください
- 研修が終わって使わなくなったら、自分のリポジトリ・Vercel のプロジェクト・Supabase のプロジェクトを削除してください（手順は [docs/troubleshooting.md](docs/troubleshooting.md#研修が終わったら)）
